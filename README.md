# 기술 세특 스튜디오

기술 교과 수업 맥락과 학생의 수행평가, 팀 프로젝트 개인 기여, 문제 해결 과정, 교사 관찰 및 성찰 근거를 바탕으로 학생부 세부능력 및 특기사항 초안을 생성하는 Vercel 웹앱입니다.

## 실행 및 배포

이 프로젝트는 별도 빌드 단계나 패키지 설치 없이 Vercel에 바로 배포할 수 있습니다.

1. 이 폴더를 Git 저장소에 올립니다.
2. Vercel에서 저장소를 가져옵니다.
3. Framework Preset은 `Other`로 둔 채 배포합니다.
4. 배포한 페이지에서 Gemini API 키를 입력해 사용합니다.

Gemini API 키는 브라우저 로컬 저장소나 서버 로그에 기록하지 않습니다. 생성 요청을 처리할 때만 Vercel 함수에서 Google Gemini API로 전달됩니다. 수업 및 학생 활동 자료도 생성 요청에 포함되므로, 학생 이름·연락처 등 직접 식별 정보는 입력하지 마세요. 임시 번호는 다운로드 파일명에만 사용하고 Gemini API에는 보내지 않습니다. 키를 입력하지 않고 환경 변수 방식으로 운영하려면 `api/generate.js`의 키 처리 방식을 배포 전에 변경할 수 있습니다.
